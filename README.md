# XCRAFT — браузерная версия

Космическая MMO-стратегия XCRAFT (Unity WebGL). Играть: https://dekmer.github.io/x_reborn_craft/

Клиент подключается к игровому серверу по `wss://153-51-113-50.sslip.io/ws`.
Другой сервер можно указать параметром ссылки: `?server=wss://host/ws`.

Сборка: Unity 6 (WebGL, Brotli с распаковкой в браузере). Этот репозиторий содержит только готовую сборку для GitHub Pages.
